# PonteEscolar - Tradutor Psicoeducacional (Projeto P0)
Projeto desenvolvido para o curso de LLM do Instituto Hardware BR (HBR).

## Problema Escolhido
Uma pessoa que realiza **atendimento e acompanhamento em psicologia escolar** precisa transformar **anotações técnicas e fragmentadas sobre o comportamento e aprendizagem de um aluno** em **dois guias práticos e sem jargões (um para o professor/equipe pedagógica e outro para a família)**, porque atualmente enfrenta **falta de tempo para redigir materiais adaptados e barreiras de comunicação causadas por termos clínicos complexos**.

## Público-Alvo
Psicólogos escolares e orientadores educacionais que precisam alinhar estratégias pedagógicas e de acolhimento entre a escola e a família.

## Justificativa para o uso de LLM
A tarefa exige adaptação de registro linguístico (traduzir termos técnicos da psicologia para linguagem didática para o docente e coloquial/empática para os pais simultaneamente), mantendo coerência semântica e ética — algo inviável com regras de programação tradicionais (`if/else`).
